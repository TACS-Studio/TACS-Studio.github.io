# TA CS 技术社区
基于 GitHub Pages 搭建的网络安全技术文档分享站点，专注Linux内核漏洞、系统安全、技术工具笔记整理与开源交流。

## 一、网站整体功能介绍
### 1. 页面导航结构
- **首页**：网站入口，汇总全部资源卡片，支持顶部全局文件搜索
- **安全文档（安全动态）**：存放内核漏洞、系统提权、漏洞补丁、安全分析技术笔记
- **关于我们**：团队介绍、站点说明、更新日志、联系方式

### 2. 侧边栏特色功能
1. 全球多时区实时时钟：北京时间、伦敦、纽约、东京、悉尼同步显示
2. 主题切换：白天亮色模式 / 夜间暗黑模式一键切换
3. 移动端全屏侧边抽屉菜单，手机端完美适配

### 3. 核心交互能力
- 文件卡片可视化展示，自动读取仓库文件生成预览卡片
- 超长文件名自动截断优化，界面整洁不排版错乱
- MD/TXT/HTML 文件在线弹窗预览，无需跳转下载
- 顶部搜索框支持文件名关键词快速检索过滤
- 底部导航直达：GitHub主页、Python工具仓库、托管仓库快捷入口

├── tools_关于我们/      # 站点介绍、更新公告、说明文档目录
├── index.html          # 网站首页主程序
